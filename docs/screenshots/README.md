# Screenshots and demo assets

Add images here so the root [README.md](../../README.md) can show a polished portfolio view on GitHub.

For **WordPress admin** or REST response screenshots, use [wordpress-export/screenshots/README.md](../../wordpress-export/screenshots/README.md).

## Recommended files

| File | What to capture |
|------|-----------------|
| `dashboard-light.png` | Project grid on the dashboard, light theme |
| `dashboard-dark.png` | Same view, dark theme |
| `project-detail.png` | Single project detail page (hero image + fields) |

Use PNG or WebP, reasonable width (e.g. 1200–1600px) so the README loads quickly.

## Optional demo GIF

| File | Suggested content |
|------|-------------------|
| `demo.gif` | Short loop: open dashboard, toggle theme, open a project, click Preview (keep under ~5–10s and compress for GitHub) |

Tools: macOS Screenshot / CleanShot, ScreenFlow, Kap, or similar.

## After exporting

Place the files in this folder (`docs/screenshots/`) with the names above. The main README references these paths; if a file is missing, the image will not render until you add it.
